# My Skills

A collection of personal Manus Agent Skills for financial analysis and trading.

## Skills

### 1. Stock Analysis
Analyze stocks and companies using financial market data. Get company profiles, technical insights, price charts, insider holdings, and SEC filings for comprehensive stock research.

### 2. Four-Eye Backtest Audit
Independent four-eye validation of trading signal backtests. Covers data integrity, statistical significance, directional bias, regime dependence, execution timing feasibility, data source integrity, and actionable improvement recommendations.

### 3. Trading Signal Dashboard
Build multi-dimensional trading signal dashboards with walk-forward backtesting. Supports gold and adaptable to other assets. Includes execution timing audit to detect look-ahead bias from asynchronous data settlement times.
